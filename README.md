# BookStoreApp

BookStoreApp is a full-stack web application built with **Spring Boot** for managing books. Users can add, view, edit, and delete books, as well as maintain a personalized book list with image upload support. 
The application uses **MySQL** as the database and follows the **MVC architecture** with controllers, services, repositories, and Thymeleaf views.

## Key Features

- Add, view, edit, and delete books  
- Upload and display book cover images  
- Maintain a personal "My Book List"  

## Technologies Used

Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Thymeleaf, HTML, CSS, Maven

## Project Structure

- **Controller:** Handles HTTP requests  
- **Service:** Business logic  
- **Repository:** Database operations  
- **Entity:** Book and MyBookList models  
- **View:** Thymeleaf templates
